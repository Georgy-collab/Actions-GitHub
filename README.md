# Time API

Простой тестовый бэкенд на FastAPI, возвращающий текущее время сервера.

## Требования

- Python 3.10+

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8002
```

Сервер будет доступен по адресу: http://127.0.0.1:8002

## Docker

В проекте есть `Dockerfile` для сборки образа приложения.

**Сборка образа:**

```bash
docker build -t time-api .
```

**Запуск контейнера:**

```bash
docker run -p 8002:8002 time-api
```

После запуска API доступен по адресам: http://127.0.0.1:8002, `/time`, `/date` и `/convert`

## Эндпоинты

| Метод | Путь       | Описание                                      |
|-------|------------|-----------------------------------------------|
| GET   | `/`        | Проверка работоспособности                    |
| GET   | `/time`    | Текущее время сервера (UTC)                   |
| GET   | `/date`    | Текущая дата сервера (UTC)                    |
| GET   | `/convert` | Конвертация времени между часовыми поясами    |

### Пример ответа `/time`

```json
{
  "utc": "2026-07-29T11:19:00.123456+00:00",
  "unix": 1785323940.123456,
  "timezone": "UTC"
}
```

### Пример ответа `/date`

```json
{
  "date": "2026-07-29",
  "year": 2026,
  "month": 7,
  "day": 29,
  "weekday": "Wednesday",
  "timezone": "UTC"
}
```

### Пример `/convert`

```bash
curl "http://127.0.0.1:8002/convert?from_tz=UTC&to_tz=Europe/Moscow&time=2026-07-31T12:00:00"
```

Параметры:

| Параметр  | Обязательный | Описание |
|-----------|--------------|----------|
| `to_tz`   | да           | Целевой пояс (`Europe/Moscow`, `America/New_York`, …) |
| `from_tz` | нет          | Исходный пояс (по умолчанию `UTC`) |
| `time`    | нет          | Время в ISO 8601; если не указано — текущее |

```json
{
  "from": {
    "timezone": "UTC",
    "time": "2026-07-31T12:00:00+00:00"
  },
  "to": {
    "timezone": "Europe/Moscow",
    "time": "2026-07-31T15:00:00+03:00"
  },
  "unix": 1785499200.0
}
```
